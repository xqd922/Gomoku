# v1.2 验收清单

构建结果、自动运行结果和真人实机结果单独记录。候选包须与记录中的源码提交对应。

## Android 手动验收

准备两位玩家，使用管理员私下提供的不同账号。另一位可以使用 Windows 或 Web。记录手机型号、Android 版本、候选包标签和网络类型；提交截图时隐藏密码。

1. 在 v1.1.0 建立一个未完成本地棋局、保留一份已完成棋谱并修改主题／声音设置。直接覆盖安装候选 APK，确认三项数据保留。
2. 离线打开，继续本地棋局、悔棋、重新开局和复盘；所有操作可达。
3. 联网进入好友对弈，应提示登录，没有注册或找回密码入口。错误密码显示明确提示，正确密码可登录。退出并重新打开应用，会话仍能恢复。
4. 在浏览器／聊天软件点开 `https://gomoku.xqd.pp.ua/join/房间码`。分别验证应用关闭和已打开时的邀请；未登录时完成登录，房间码仍在，并由玩家点击加入。
5. 两个账号创建／加入、双方准备、交替落子、协商悔棋、走完一局、复盘、再来一局；下一局黑白交换。另一端应看到相同棋谱。
6. 对局中切后台和锁屏约 30 秒，再返回；局面恢复且没有重复落子。切换 Wi-Fi／移动网络，确认重新连接并清除旧预选。
7. 断网约 30 秒后重连，应继续原局；再进行一次超过 120 秒的断线，棋局应记为中断。服务器通过心跳租约发现断线可能额外需要约 25 秒。
8. 返回首页保留续局；主动退出房间有认输提示。横屏、深浅主题、2 倍字号、声音／触感开关均可正常操作。

反馈格式：`候选标签；手机／系统；步骤 1–8 通过或失败；失败时操作与现象`。若有失败，记录大致时间和房间码，便于匹配服务器日志。

## 自动和桌面验收

- 真实 PostgreSQL／Redis：权限、幂等、并发、过期、断线、服务重启、多实例通知、会话撤销、账号隔离和棋谱同步。
- 公网 HTTPS／Cookie／WebSocket／Wasm 头和 App Links 关联文件；Web 离线和多标签页。
- Windows 发行包实际启动并与 Web 对弈；构建证据不能代替实际运行。
- 10 个客户端、两个账号，持续 60 分钟；落子确认 P95 ≤ 2 秒，无 OOM、异常重启或局面分歧。
- 数据库备份下载到本机私有目录，在本机隔离数据库执行恢复；至少保留 500 MiB 服务器磁盘空间；原 Xray 链路回归。
