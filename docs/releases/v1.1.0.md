# Gomoku v1.1.0 / 五子棋

本版重新组织了整个界面：各平台统一为“对弈／棋谱”两个顶部标签，账户和设置集中到头像入口。采用更鲜明的 Material 3 Expressive 配色、圆角、字体层级和操作反馈，让开局、续局和复盘更直接。

## 本版变化

- 首页提供开局与续局面板，优先恢复进行中的好友房间，再恢复未完成的本地棋局；最近棋谱改为紧凑列表。
- 好友对弈统一创建和加入入口，邀请链接预填房间码；等待房间突出双方座位、准备状态和复制邀请。
- 对局采用专用布局：手机固定落子确认操作区，横屏和大屏使用棋盘＋信息栏；360×640 常规字号可同时看到完整棋盘、当前回合和确认按钮。
- 预选显示坐标并支持取消；悔棋、断线重连和提交状态有明确反馈。返回首页保留棋局，主动退出房间时确认认输后果。
- 棋谱按日期分组，显示双方、结果、时间、手数和棋盘缩略图；复盘集中滑块与播放控制，并支持方向键、Home／End 和 Space。
- 设置按外观、对局、语言与无障碍分组；账户按登录、注册、邮箱验证和找回密码的步骤呈现，就近显示字段错误。
- 保留中英文、深浅主题、平台动态配色、触屏／鼠标／键盘、双倍字号、225 点读屏语义和减少动画支持。
- 修复二级页面的 Web 地址、前进／后退和刷新恢复；修复刚结束棋局保存稍晚时复盘无法显示的问题，以及账户页面退出时的状态访问问题。

[主要页面前后对比与设计说明](https://github.com/xqd922/Gomoku/blob/v1.1.0/docs/UI_REDESIGN.md)。

## 下载与运行

| 文件 | 用途 |
| --- | --- |
| `Gomoku-1.1.0-windows-x64.zip` | 解压完整目录后运行 `Gomoku.exe`，保留 DLL 与 data 目录 |
| `Gomoku-1.1.0-android.apk` | 通用 APK，沿用原有正式证书签名 |
| `Gomoku-1.1.0-linux-x64.tar.gz` | 解压后进入 Gomoku 目录执行 `./Gomoku`；Ubuntu 24.04 或兼容环境 |
| `Gomoku-1.1.0-macos-universal.zip` | Intel／Apple Silicon 通用 app，macOS 12 或更高；尚未公证 |
| `Gomoku-1.1.0-ios-unsigned.zip` | iOS 15 或更高的无签名 app，需要开发者签名后安装 |
| `Gomoku-1.1.0-web.zip` | 静态 Web 资源，按部署文档配置同源代理和数据库 worker／Wasm 响应头 |
| `SHA256SUMS.txt` | 发行文件的 SHA-256 校验和 |
| `build-info.json` | 本次源码提交、版本与 Actions 构建来源 |
| `android-signature.txt` | Android 签名验证结果及公开证书指纹 |
| `RELEASE_NOTES.md` | 本发行说明的离线副本 |

Windows 需要 [Microsoft Visual C++ v14 x64 运行库](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。Linux 需要 GTK3、libsecret 和 GStreamer 运行库；macOS 和 Windows 产物没有开发者代码签名。

本地双人无需后端。好友联机、账户和跨设备同步需要自建服务；发行包未连接公共游戏服务器，原生默认地址用于本机开发。部署后按 [部署说明](https://github.com/xqd922/Gomoku/blob/v1.1.0/docs/DEPLOYMENT.md) 配置实际 HTTPS 地址并构建客户端，Web 使用同源部署，邮件通过自有 SMTP 发送。

## 升级与兼容

v1.1.0 沿用 v1.0.0 的棋谱、设置与数据库格式及服务端接口，无新增数据库迁移。Android 保留 `com.xqd922.gomoku` 和原有签名，versionCode 从 **10000** 提升为 **10100**；覆盖安装尚未经过 Android 实机验证。本地 debug-key APK 与公开正式签名包的签名不同，不能视为同一升级路径。

## 验证范围

改版源码已通过 12 项规则测试、39 项 Flutter／SQLite 测试、11 项真实后端集成测试和 9 组 Chrome 浏览器场景。正式标签的 Actions 会重新执行这些检查、生产镜像构建和六端打包，全部成功后才公开本 Release；实际构建来源以 `build-info.json` 为准。

已完成浏览器桌面与触屏模拟的自动化运行，以及 Windows 发布程序启动检查；未进行六平台全部真人实机操作和真人屏幕阅读器验收。iOS 产物无签名。具体边界见 [验证记录](https://github.com/xqd922/Gomoku/blob/v1.1.0/docs/VALIDATION.md)。
