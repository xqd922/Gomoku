# Gomoku v1.6.0 · 界面完全重写

版本 `1.6.0+10600`。这一版丢弃了旧的页面实现，先建一套组件套件，再用它把每个屏幕从零写了一遍——全面采用 FlClash 的界面语言：浮动工具条、卡片分区、锚点变形菜单、响应式弹层。规则、联机协议和服务端裁定都没有改。

- **组件套件**：新增 `lib/ui/kit` —— 浮动工具条页面壳（标题、可折叠动作、栏内搜索）、卡片与分区表面、锚点变形弹出菜单（从触发位置"长出"卡片，支持一层子菜单与危险项红标）、响应式弹层分流（窄屏底部弹层 / 宽屏侧滑面板 / 确认对话框）、骨架屏与组合式空状态。自研实现，未复制 FlClash（GPL-3.0）源码。
- **对局**：改为卡片仪表盘——一张 `primaryContainer` 主开局大卡，加继续对局、好友对弈、同屏、战绩、服务状态五张磁贴，随宽度重排，弹簧入场。
- **联机**：房间创建/加入收进分区卡，等待中的房间变为一键加入的行卡，连接状态用胶囊提示。
- **棋谱**：工具条内置搜索（按棋手或结果过滤），筛选胶囊与日期分组保留，加载显示骨架屏，空状态改为插画 + 错峰。
- **我的**：个人头部卡 + 全部账户与偏好设置改为套件分区行；外观、对局、无障碍的设置项一个不少。
- **对局中**：棋盘上方是浮动工具条（返回 + 标题 + 变形菜单），宽屏右侧为卡片信息面板，房间信息改走侧滑面板；确认落子、悔棋、断线倒计时逻辑与键盘、语义全部不变。
- **设计记录**：`DESIGN.md` 组件章节记录浮动工具条、卡片仪表盘、变形菜单与弹层分流。

验证:`./tool/check.ps1` 全套通过（dart format 门禁、`dart analyze --fatal-infos` 无问题、gomoku_core 12 项、gomoku_app 63 项测试，含 11 组视口矩阵与 7 项组件套件新测试）；根锁文件与 `infra/server.pubspec.lock` 一致。`tool/browser` 自动验收 9 个场景全部通过、零运行时异常：深链接与前进后退、建房加入、HttpOnly 会话、完整对局含悔棋与胜利线、断线暂停恢复、复盘、邮箱注册与双设备登录、Drift 多标签与离线、深色/英文/横屏——全部在重写后的界面上执行。以上是自动检查结果，不是真机验收。无协议变更，无数据库迁移。六端客户端与 Debian 12 服务端构建由 v1.6.0 标签流水线执行，全部成功后才发布。

Android 使用既有正式证书，versionCode 10600，可直接覆盖安装 v1.5.0；Windows 解压后运行 `Gomoku.exe`；macOS 未公证；iOS 包未签名。

服务端行为与 v1.5.0 相同，版本号改为 1.6.0，可不升级。升级使用 `manage.py install Gomoku-1.6.0-server-debian12-x64.tar.gz`（Docker 部署则更新镜像后 `docker compose up -d`）。无新增迁移，不升级也不影响现有房间与棋谱。
