# Gomoku v1.2.2 · 界面打磨

版本 `1.2.2+10202`。在 v1.2.1 基础上根据试用反馈打磨三处界面，玩法、联机与部署形态不变。

- 首页聚焦对弈：移除与"棋谱"标签重复的"最近棋局"列表；保留"继续对局 / 返回房间"续玩入口和"好友联机 / 本地双人"快捷方式，已结束的棋局只在"棋谱"标签中查看。
- 右上角账户头像与整体设计统一：改为圆形，未登录时为浅底细描边的人形图标，登录后为主题色圆底加昵称首字；入口位置与"账户 / 设置"菜单不变。
- 私有账号登录换用专用界面：直接在"账号 1 / 账号 2"两张卡片中选择玩家，输入管理员提供的 8 位数字密码即可；不再出现邮箱式表单和"输入 1 或 2"提示。注册、验证码、找回密码在私有模式下本就被服务端禁用，界面不再展示相关入口。服务端接口未改动。

验证：静态分析零问题；核心规则 12 项与客户端 48 项测试（私有联机测试已改走新登录界面）全部通过。六端客户端与 Debian 12 服务端构建由标签流水线执行，全部成功后才发布。

Android 使用既有正式证书，versionCode 10202，可直接覆盖安装 v1.2.1 或 v1.2.0，不要先卸载旧版；Windows 解压后运行 `Gomoku.exe`；macOS 未公证；iOS 包未签名。服务端无行为变更，升级仍使用 `manage.py install`，见 [原生部署方案](../NATIVE_DEPLOYMENT.md)。
