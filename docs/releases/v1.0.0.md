# Gomoku v1.0.0 / 五子棋

首个 Flutter / Serverpod 六端版本，界面采用 Material 3 Expressive 设计语言，支持简体中文、英语、深浅主题、Android 动态配色和大小屏布局。

## 本版功能

- 15×15 本地双人五子棋，无禁手；预选确认、悔棋、自动保存、胜负提示与逐步复盘。
- 六位房间码 / 邀请链接，好友联机、双方准备、协商悔棋、认输和换色再来一局。
- 断线暂停并保留座位 120 秒；服务端事务裁定、命令幂等与快照恢复。
- 游客直接游玩，邮箱账号、验证与密码找回；游客棋谱归并和账号跨设备同步。
- 键盘、鼠标、触屏、大字体、无障碍语义、减少动画和声音 / 触感设置。
- Web 本地字体、离线资源和多标签页持久化。

## 下载与运行

| 文件 | 用途 |
| --- | --- |
| `Gomoku-1.0.0-windows-x64.zip` | 解压整个目录，运行 `Gomoku.exe`；保留 DLL 和 data 目录 |
| `Gomoku-1.0.0-android.apk` | 通用 APK，使用仓库原有正式证书签名 |
| `Gomoku-1.0.0-linux-x64.tar.gz` | 解压后进入 Gomoku 目录执行 `./Gomoku`；Ubuntu 24.04 或兼容环境 |
| `Gomoku-1.0.0-macos-universal.zip` | Intel / Apple Silicon 通用 app，macOS 12 或更高；尚未公证 |
| `Gomoku-1.0.0-ios-unsigned.zip` | iOS 15 或更高的无签名 app 构建，供开发者签名，不能直接安装 |
| `Gomoku-1.0.0-web.zip` | 静态 Web 资源，需按部署文档配置同源代理和数据库 Wasm 响应头 |
| `SHA256SUMS.txt` | 发行文件的 SHA-256 校验和 |
| `build-info.json` | 源码提交、版本与 Actions 构建来源 |
| `android-signature.txt` | Android 签名验证结果及公开证书指纹 |

Windows 需要 [Microsoft Visual C++ v14 x64 运行库](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。Linux 需要 GTK3、libsecret 和 GStreamer 运行库。macOS 与 Windows 没有开发者代码签名；系统可能要求确认应用来源。

本版可直接游玩本地双人。账号、好友联机和跨设备同步需要自建后端；发行包未连接公共游戏服务器，原生默认地址用于本机开发。部署后按 [部署说明](https://github.com/xqd922/Gomoku/blob/v1.0.0/docs/DEPLOYMENT.md) 配置实际 HTTPS 地址并构建客户端；Web 使用同源部署。邮件通过自有 SMTP 发送。

## 从旧版升级

Android 沿用 `com.xqd922.gomoku` 和 v0.3.0 的签名证书，versionCode 提升为 **10000**，具备覆盖安装条件。旧版 Tauri 的本地数据格式和 WebSocket 服务与本版不同，未提供旧棋谱迁移；不要把新版联机客户端连接到旧服务器。覆盖安装及数据行为尚未经过 Android 实机验证。仓库旧版本和提交历史均保留。

从本地 debug-key APK 升级到正式签名 APK 时，Android 可能因签名不同拒绝覆盖安装；卸载会清除本地数据，应先保留需要的内容。

## 验证范围

发布工作流必须完成规则、Flutter / SQLite、真实 PostgreSQL / Redis / Mailpit 集成测试、Chrome 浏览器流程、部署镜像和全部六端构建，才会发布这些文件。具体记录见 [VALIDATION.md](https://github.com/xqd922/Gomoku/blob/v1.0.0/docs/VALIDATION.md)；编译和自动化检查不等于实机验收，Android / iOS 尚无实机验证。

本版不含 AI、在线匹配、排行榜或商店上架。
