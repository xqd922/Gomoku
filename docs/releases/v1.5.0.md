# Gomoku v1.5.0 · 底部导航与弹簧动效

版本 `1.5.0+10500`。这一版重排界面骨架：像主流应用一样使用底部导航栏，宽屏切换侧边栏；账户与设置归入「我的」；全线换用超椭圆形状并移植一套弹簧动效语言。规则、联机协议和服务端裁定都没有改。

- **自适应导航**：新增底部导航栏四个目的地——对局、联机、棋谱、我的；宽度 ≥840 自动变为左侧导航栏。联机大厅从二级页提升为标签，等待中的房间一键加入入口更浅；对局、房间与复盘仍为全屏沉浸路由。
- **我的**：账户、外观、对局偏好、无障碍与关于合并为一个标签；旧链接 `/account`、`/settings` 自动跳转，登录后仍会回到邀请链接的目的地。
- **超椭圆形状**：卡片、对话框、底部弹层、菜单、芯片、SnackBar 与导航指示器全部使用曲率连续的 `RoundedSuperellipseBorder`，由 `withAppShapes` 一次注入主题；按钮保持胶囊形。
- **弹簧动效**：新增 `SpringCurve`（弹簧手感、确定时长）与按压回弹、列表错峰入场、共享 X 轴页面转场、对话框缩放淡入、切标签的淡入滑动与触觉反馈；对局结果改为弹簧登场，落子改为弹簧沉降，胜利线沿线生长后五子逐个脉冲，预选棋子会轻轻呼吸。全部动效尊重系统与应用内的「减少动画」。
- **设计记录**：`DESIGN.md` 同步改写导航、形状与动效章节，`motion.dart`、`shape.dart` 成为令牌事实源。

验证:`./tool/check.ps1` 全套通过（dart format 门禁、`dart analyze --fatal-infos` 无问题、gomoku_core 12 项、gomoku_app 56 项测试，含 11 组视口×语言×字号×主题矩阵）；根锁文件与 `infra/server.pubspec.lock` 一致（新增 `animations` 依赖后按部署文档用 Docker 重新生成）。`tool/browser` 自动验收 9 个场景全部通过、零运行时异常：深链接与前进后退、建房加入、HttpOnly 会话、完整对局含悔棋与胜利线、断线暂停恢复、复盘、邮箱注册与双设备登录、Drift 多标签与离线、深色/英文/横屏。以上是自动检查结果，不是真机验收。无协议变更，无数据库迁移。六端客户端与 Debian 12 服务端构建由 v1.5.0 标签流水线执行，全部成功后才发布。

Android 使用既有正式证书，versionCode 10500，可直接覆盖安装 v1.4.1；Windows 解压后运行 `Gomoku.exe`；macOS 未公证；iOS 包未签名。

服务端行为与 v1.4.1 相同，版本号改为 1.5.0，可不升级。升级使用 `manage.py install Gomoku-1.5.0-server-debian12-x64.tar.gz`（Docker 部署则更新镜像后 `docker compose up -d`）。无新增迁移，不升级也不影响现有房间与棋谱。
