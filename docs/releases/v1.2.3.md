# Gomoku v1.2.3 · 设计系统统一

版本 `1.2.3+10203`。引入 DESIGN.md 作为界面设计的事实来源,并完成一轮全局一致性收敛;玩法、联机与服务端行为不变。

- 新增根目录 `DESIGN.md`,经 Google design.md 官方 lint 校验:完整记录紫色种子生成的明暗两套配色方案、固定的棋盘物理色板、形状与间距尺度、动效规范、可访问性要求与反模式清单(禁纯黑棋子、禁界面阴影、禁多强调色等),作为后续界面演进的对照标准。
- 棋子颜色统一为单一色板(`board_palette.dart`):棋盘绘制、玩家头像、棋谱缩略图此前使用三处接近但不相同的黑色,现在共用同一组炭黑(#302D35)/瓷白(#FFFDFA)棋子色与边线,任何位置的棋子观感完全一致。
- 圆角与形状全部令牌化:首页横幅 88/56 非对称切角、芯片与缩略图 14、空棋谱状态 26→28、色板圆角 36→32 等散落值收敛到统一形状尺度,消除魔法数字。
- 右上角头像、账号卡片、状态胶囊等近期组件的形状值同步对齐到令牌。

验证:静态分析零问题;核心规则 12 项与客户端 48 项测试全部通过;DESIGN.md 通过官方 CLI lint。六端客户端与 Debian 12 服务端构建由标签流水线执行,全部成功后才发布。

Android 使用既有正式证书,versionCode 10203,可直接覆盖安装前序版本;Windows 解压后运行 `Gomoku.exe`;macOS 未公证;iOS 包未签名。服务端无行为变更,升级使用 `manage.py install`,见 [原生部署方案](../NATIVE_DEPLOYMENT.md)。
