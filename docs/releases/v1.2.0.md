# Gomoku v1.2.0 · 亲友联机

版本 `1.2.0+10200`。正式服务地址为 <https://gomoku.xqd.pp.ua>，联机使用管理员提供的两个固定账号；本地双人无需登录。保留 v1.1 的 Material 3 Expressive 界面、棋谱和设置。

- 正式站点关闭游客联机、注册、验证码和自助找回密码。账号和密码由管理员私下提供，发行包不包含凭证。
- 邀请链接在登录后保留房间码，由玩家确认加入。Android 支持已验证的 App Links。
- 重连先恢复会话，再读取权威局面和建立订阅；权限失效停止自动重试。
- 六端客户端均配置正式 HTTPS 地址，新增 Debian 12 服务端 AOT／Web 部署包、初始化、升级、回滚及备份恢复工具。

带 `-rc.N` 的标签是候选版，供线上和真人实机验收使用。`v1.2.0-acceptance.json` 分别记录构建、线上自动验证及实机验证。正式版本须通过全部发布门槛；候选包构建成功不代表实机验收已通过。

Android 使用既有正式证书，支持覆盖 v1.1.0 安装；不要先卸载旧版。Windows 解压后运行 `Gomoku.exe`。macOS 未公证；iOS 包未签名，需要在 macOS 上另行签名安装。初始账号密码不会放入公开 Release 或源码。

Android 手动验收步骤见 [v1.2 验收清单](../V1_2_ACCEPTANCE.md)。原生部署和恢复见 [部署说明](../NATIVE_DEPLOYMENT.md)。
